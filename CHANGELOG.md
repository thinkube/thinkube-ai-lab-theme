## 0.2.1

- Side bar tab icons use thicker lines (about 2px), matching the VS Code
  activity bar.
- The extension manager uses the Lucide `blocks` icon, as in VS Code.

## 0.2.0

- Replace JupyterLab's single-color UI icons with Lucide icons. The file
  browser tab uses the Lucide `folder-tree` icon. Turn this off with the
  "Use Lucide icons" setting in Settings > Thinkube Icons.
